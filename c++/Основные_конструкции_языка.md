# 📘 Основные конструкции языка

## 1. Базовые типы данных

| Тип | Размер (обычно) | Диапазон | Пример |
|-----|----------------|----------|--------|
| `int` | 4 байта | ≈ ±2·10⁹ | `int age = 18;` |
| `float` | 4 байта | ±3.4·10³⁸ (7 знаков) | `float pi = 3.14f;` |
| `double` | 8 байт | ±1.7·10³⁰⁸ (15 знаков) | `double e = 2.71828;` |
| `char` | 1 байт | -128..127 или 0..255 | `char letter = 'A';` |
| `bool` | 1 байт | `true` / `false` | `bool isReady = true;` |
| `string` | переменный | (нужен `#include <string>`) | `string name = "Alice";` |

**Модификаторы:** `short`, `long`, `unsigned`, `signed` (например, `unsigned int`).

## 2. Ввод и вывод (консоль)

Подключите `#include <iostream>` и `using namespace std;` (или используйте `std::`).

```cpp
#include <iostream>
#include <string>
#include <iomanip>   // для форматирования
using namespace std;

int main() {
    // ----- ВЫВОД -----
    cout << "Привет, мир!" << endl;   // endl – перевод строки
    cout << "Число: " << 42 << "\n";  // \n – тоже перевод

    // ----- ВВОД -----
    int x;
    double y;
    string s;
    cout << "Введите целое, вещественное и слово: ";
    cin >> x >> y >> s;   // разделяются пробелом / переводом строки

    // Ввод строки с пробелами (целиком)
    cin.ignore(); // очистка буфера после cin >>
    getline(cin, s); // читает всю строку до '\n'

    // Форматированный вывод
    cout << fixed << setprecision(2) << 3.14159; // выведет 3.14
    cout << setw(10) << 42; // ширина поля 10

    return 0;
}
```

## 3. Условные операторы

### if / else if / else
```cpp
int score = 85;
if (score >= 90) {
    cout << "Отлично!";
} else if (score >= 70) {
    cout << "Хорошо";
} else {
    cout << "Попробуй ещё";
}
```

### Тернарный оператор (условие ? значение1 : значение2)
```cpp
int a = 5, b = 10;
int maxVal = (a > b) ? a : b;   // maxVal = 10
```

### switch (сравнение с целыми / символами)
```cpp
char grade = 'B';
switch (grade) {
    case 'A': cout << "Отлично"; break;
    case 'B': cout << "Хорошо"; break;
    case 'C': cout << "Удовл."; break;
    default:  cout << "Неизвестно";
}
```

## 4. Циклы

### while (с предусловием)
```cpp
int i = 0;
while (i < 5) {
    cout << i << " ";
    i++;
}
```

### do-while (с постусловием – выполнится хотя бы раз)
```cpp
int n;
do {
    cout << "Введите число > 0: ";
    cin >> n;
} while (n <= 0);
```

### Все формы `for`

#### 4.1 Классический `for` (счётчик)
```cpp
for (int i = 0; i < 10; ++i) {
    cout << i << " ";   // 0 1 2 ... 9
}
```

#### 4.2 `for` с несколькими переменными
```cpp
for (int i = 0, j = 10; i < j; ++i, --j) {
    cout << i << " " << j << endl;
}
```

#### 4.3 Пропущенные части (бесконечный и т.п.)
```cpp
int i = 0;
for (; i < 5; ) {      // условие есть, инкремент в теле
    cout << i++;
}

for (;;) {             // бесконечный цикл
    // break для выхода
}
```

#### 4.4 Диапазонный `for` (range‑based for, он же «foreach», C++11)
```cpp
int arr[] = {1, 2, 3, 4, 5};
for (int val : arr) {
    cout << val << " ";
}

// Для векторов, строк, списков – всё, что имеет begin/end
#include <vector>
vector<int> v = {10, 20, 30};
for (int x : v) { ... }

// С auto – удобно и безопасно
for (auto x : v) { ... }            // копия (для маленьких типов)
for (const auto& x : v) { ... }     // читаем без копирования (рекомендуется)
for (auto& x : v) { x *= 2; }       // изменяем элементы
```

#### 4.5 `std::for_each` – функциональный стиль (нужен `<algorithm>`)
```cpp
#include <algorithm>
#include <vector>

vector<int> v = {1, 2, 3};
for_each(v.begin(), v.end(), [](int x) {
    cout << x << " ";
});

// Или с обычной функцией
void print(int x) { cout << x << " "; }
for_each(v.begin(), v.end(), print);

// С лямбдой для изменения
for_each(v.begin(), v.end(), [](int& x) { x *= 2; });
```

### Какую форму выбрать?

| Ситуация | Рекомендуемый цикл |
|----------|-------------------|
| Нужен индекс или работа с позицией | Классический `for (int i=0; i<n; ++i)` |
| Перебор всех элементов (чтение) | `for (const auto& x : container)` |
| Перебор с изменением элементов | `for (auto& x : container)` |
| Функция применяется к каждому элементу | `std::for_each` + лямбда |
| Бесконечный цикл с выходом по условию | `for (;;) { if (...) break; }` или `while (true)` |

## 5. Примеры программ

### Пример 1: Калькулятор (ввод, условия, switch)
```cpp
#include <iostream>
using namespace std;

int main() {
    double a, b;
    char op;
    cout << "Введите выражение (например, 5 + 3): ";
    cin >> a >> op >> b;
    switch (op) {
        case '+': cout << a + b; break;
        case '-': cout << a - b; break;
        case '*': cout << a * b; break;
        case '/': 
            if (b != 0) cout << a / b;
            else cout << "Деление на ноль!";
            break;
        default: cout << "Неизвестная операция";
    }
    return 0;
}
```

### Пример 2: Сумма чисел от 1 до N (for)
```cpp
int n, sum = 0;
cout << "Введите N: ";
cin >> n;
for (int i = 1; i <= n; ++i) {
    sum += i;
}
cout << "Сумма = " << sum;
```

### Пример 3: Поиск максимума в массиве (for + условие)
```cpp
int arr[] = {3, 7, 1, 9, 4};
int size = 5;
int maxVal = arr[0];
for (int i = 1; i < size; ++i) {
    if (arr[i] > maxVal) {
        maxVal = arr[i];
    }
}
cout << "Максимум: " << maxVal;
```

### Пример 4: Ввод чисел до 0 (while)
```cpp
int num, sum = 0;
cout << "Вводите числа (0 для выхода): ";
cin >> num;
while (num != 0) {
    sum += num;
    cin >> num;
}
cout << "Сумма = " << sum;
```

### Пример 5: Перебор строки диапазонным for
```cpp
string str = "hello";
for (char ch : str) {
    cout << ch << "-";   // h-e-l-l-o-
}
```

## 6. Полезные мелочи

- **Комментарии:** `// однострочный` и `/* многострочный */`
- **Логические операции:** `&&` (И), `||` (ИЛИ), `!` (НЕ)
- **Сравнение:** `==`, `!=`, `<`, `>`, `<=`, `>=`
- **Инкремент / декремент:** `i++` (постфиксный), `++i` (префиксный)
- **Пространства имён:** `using namespace std;` или пишите `std::cout`
- **Основные заголовочные файлы:**
  - `<iostream>` – ввод/вывод
  - `<string>` – строки
  - `<iomanip>` – форматирование (`setprecision`, `setw`)
  - `<algorithm>` – `for_each`, `sort`, и др.
  - `<cmath>` – математические функции
