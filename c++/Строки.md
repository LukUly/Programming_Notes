# Шпаргалка: Строки в C++ (`std::string`)

## Что такое строка
`std::string` (из `<string>`) — **изменяемая** упорядоченная коллекция символов.  
В отличие от Python, строки в C++ можно менять на месте (по индексу, через методы).

```cpp
#include <string>
std::string s = "Привет";
s[0] = 'п';  // OK, строка изменяется
```

**Аналогия в Python:** строки неизменяемы, любое изменение создаёт новую.

---

## Создание строки

```cpp
#include <string>
using namespace std;

// Из литерала
string s1 = "Hello";

// Из C-строки (массив char)
const char* cstr = "World";
string s2(cstr);

// Из части C-строки
string s3(cstr, 3);   // "Wor"

// Повтор символа n раз
string s4(5, 'a');    // "aaaaa"

// Из другой строки (копия)
string s5(s1);

// Из части другой строки
string s6(s1, 1, 3);  // "ell" (с индекса 1 длиной 3)

// Пустая строка
string empty;
```

**Аналог в Python:**
```python
s1 = "Hello"
s2 = "World"
s3 = s2[:3]     # "Wor"
s4 = 'a' * 5    # "aaaaa"
s5 = s1         # копия
```

## Индексация и доступ

- Индексация с **0**. Отрицательных индексов нет.
- Для доступа: `operator[]` (без проверки границ) и `at()` (с проверкой, бросает `std::out_of_range`).
- Длина: `size()` или `length()`.

```cpp
string s = "Python";
cout << s[0];          // P
cout << s.at(0);       // P
cout << s[s.size()-1]; // n (последний)
cout << s.back();      // n (C++11)
cout << s.front();     // P
```

**Аналог в Python:** `s[0]`, `s[-1]`, `len(s)`. В C++ нужно вычислять `s.size()-1`.

## Срезы

В C++ нет встроенного синтаксиса срезов. Используются методы:
- `substr(pos, count)` — возвращает новую строку (подстроку).
- `erase(pos, count)` — удаляет часть (изменяет текущую).
- `insert(pos, substr)` — вставляет подстроку.
- `assign(...)` — заменяет содержимое.

```cpp
string s = "Программирование";
cout << s.substr(0, 5);      // "Прогр"
cout << s.substr(5);         // "аммирование" (до конца)

// Реверс через алгоритмы
string rev = s;
reverse(rev.begin(), rev.end());
cout << rev;                 // "еинавориммаргоП"
```

**Аналог в Python:** срезы `s[0:5]`, `s[5:]`, `s[::-1]` (реверс — `reverse` в C++).

## Основные операции

| Операция | Пример (C++) | Результат | Аналог в Python |
|----------|--------------|-----------|-----------------|
| Длина | `s.size()` | `size_t` | `len(s)` |
| Конкатенация | `s1 + s2` | новая строка | `s1 + s2` |
| Присоединение | `s1 += s2` | изменяет `s1` | `s1 += s2` (создаёт новую) |
| Повторение | нет оператора, но можно: `string(3, 'a')` | `"aaa"` | `'a' * 3` |
| Проверка вхождения | `s.find(sub) != npos` | `bool` | `sub in s` |
| Сравнение | `s1 == s2`, `s1 < s2` | `bool` | `s1 == s2`, `s1 < s2` |

```cpp
string a = "Hello";
string b = "World";
string c = a + " " + b;   // "Hello World"
a += "!";                 // a теперь "Hello!"
bool has = a.find("ell") != string::npos; // true
```

## Методы строк (таблица)

Все методы, которые изменяют строку, делают это на месте (ничего не возвращают или возвращают ссылку).

| Категория | Метод | Описание | Пример (C++) | Аналог в Python |
|-----------|-------|----------|--------------|-----------------|
| **Поиск** | `s.find(sub, pos)` | Индекс первого вхождения `sub` начиная с `pos` (по умолчанию 0) или `npos` | `s.find("lo")` → `3` | `s.find(sub)` (возвращает -1) |
| | `s.rfind(sub)` | Индекс последнего вхождения | `s.rfind("l")` → `3` | `s.rfind(sub)` |
| | `s.find_first_of(chars)` | Индекс первого символа из набора `chars` | `s.find_first_of("ae")` | нет прямого аналога |
| | `s.find_first_not_of(chars)` | Индекс первого символа НЕ из набора | `s.find_first_not_of(" \t")` | нет |
| | `s.find_last_of`, `find_last_not_of` | Аналогично с конца | | |
| **Замена** | `s.replace(pos, len, new)` | Заменяет часть `len` символов на `new` (может менять длину) | `s.replace(0,2,"X")` | `s.replace(old, new)` но здесь позиции |
| | `s.erase(pos, len)` | Удаляет `len` символов с позиции `pos` | `s.erase(2,3)` | нет (можно срезом и конкатенацией) |
| | `s.insert(pos, sub)` | Вставляет `sub` в позицию `pos` | `s.insert(2,"XX")` | нет |
| | `s.assign(sub)` | Заменяет всё содержимое на `sub` | `s.assign("new")` | `s = "new"` |
| | `s.append(sub)` | Добавляет в конец (эквивалент `+=`) | `s.append("!")` | `s += "!"` |
| **Извлечение** | `s.substr(pos, count)` | Возвращает новую строку (подстроку) | `s.substr(1,3)` | `s[1:4]` |
| **Проверка** | `s.empty()` | Пустая ли строка? | `s.empty()` → `true` | `not s` или `len(s)==0` |
| | `s.size()` / `s.length()` | Длина | `s.size()` | `len(s)` |
| **Изменение размера** | `s.resize(n, ch)` | Изменяет размер до `n`; если больше, дополняет `ch` | `s.resize(10,'.')` | нет |
| | `s.reserve(n)` | Резервирует память (не меняет размер) | | нет |
| | `s.clear()` | Очищает строку (делает пустой) | `s.clear()` | `s = ""` или `s.clear()` (Python нет) |
| **Доступ к буферу** | `s.c_str()` | Возвращает `const char*` (нуль-терминированная C-строка) | `const char* p = s.c_str();` | `s.encode()` или `bytes(s, 'utf-8')` |
| | `s.data()` | То же, но без гарантии нуль-терминации (C++17 даёт) | | |
| **Сравнение** | `s.compare(other)` | Сравнивает, возвращает 0, <0, >0 | `s.compare("abc")` | `s == other`, `s < other` и т.д. |
| **Преобразование регистра** | Нет встроенных, используется `<cctype>` + алгоритмы | | `s.lower()` и `s.upper()` в Python |
| **Проверки символов** | Функции из `<cctype>`: `isalpha(c)`, `isdigit(c)`, `isalnum(c)`, `islower(c)`, `isupper(c)`, `isspace(c)` – применяются к каждому символу | | `s.isalpha()`, `s.isdigit()` и т.д. в Python |

⚠️ В C++ нет встроенных методов для `strip`, `startswith`, `endswith`, `split`, `join` – их нужно реализовывать вручную.

## Примеры часто используемых операций

### Изменение регистра (через алгоритм)
```cpp
#include <algorithm>
#include <cctype>

string s = "Hello";
transform(s.begin(), s.end(), s.begin(), ::tolower); // "hello"
transform(s.begin(), s.end(), s.begin(), ::toupper); // "HELLO"
```

### Удаление пробелов (strip)
```cpp
string s = "  hello  ";
size_t start = s.find_first_not_of(" \t\n");
size_t end = s.find_last_not_of(" \t\n");
if (start == string::npos) s.clear();
else s = s.substr(start, end - start + 1);
```

### Проверка начала/конца
```cpp
string s = "Hello world";
if (s.compare(0, 5, "Hello") == 0) { /* starts with Hello */ }
if (s.size() >= 3 && s.compare(s.size()-3, 3, "rld") == 0) { /* ends with rld */ }
// или через find (но аккуратно с позицией)
```

### Разбиение (split) нет – пишут вручную, например через `find` в цикле.

## Обход строки

```cpp
string s = "Python";

// По индексу
for (size_t i = 0; i < s.size(); ++i) {
    cout << s[i];
}

// По итераторам
for (auto it = s.begin(); it != s.end(); ++it) {
    cout << *it;
}

// Range-based for (C++11)
for (char ch : s) {
    cout << ch;
}
```

**Аналог в Python:** циклы `for ch in s`, `for i in range(len(s))`, `enumerate`.

## Преобразование в другие типы

```cpp
#include <string>
// Строка → число
int i = stoi("123");        // 123
long l = stol("123456");
double d = stod("3.14");

// Число → строка (C++11)
string num = to_string(42); // "42"
```

**Аналог в Python:** `int("123")`, `str(42)`.

## Полезные функции (алгоритмы)

```cpp
#include <algorithm>
#include <string>

string s = "cba";
sort(s.begin(), s.end());                // "abc"
reverse(s.begin(), s.end());             // "cba"

// Поиск максимума/минимума символа (по коду)
char max_ch = *max_element(s.begin(), s.end());
char min_ch = *min_element(s.begin(), s.end());
```

**Аналог в Python:** `sorted(s)`, `max(s)`, `min(s)`.

## Важные отличия от Python

| Особенность | C++ | Python |
|-------------|-----|--------|
| Изменяемость | **Да** (можно менять символы на месте) | **Нет** (все операции создают новую) |
| Срезы | `substr` или удаление/вставка | `s[start:stop:step]` |
| Отрицательные индексы | Нет, только `s.size()-1` | Да (`-1` — последний) |
| `find` возвращает | `size_t` или `string::npos` (константа) | `int` или `-1` |
| Регистр и проверки | Нет методов, используются функции `<cctype>` + циклы | Есть методы `.upper()`, `.isalpha()` и т.д. |
| `strip`, `split`, `join` | Нет встроенных – пишутся вручную | Есть |
| Сравнение | `==`, `<`, `>` работают лексикографически | аналогично |

## Главное запомнить

| Что сделать? | Как в C++ |
|--------------|-----------|
| Получить символ по индексу | `s[i]` или `s.at(i)` |
| Длина | `s.size()` / `s.length()` |
| Подстрока | `s.substr(pos, count)` |
| Найти подстроку | `size_t p = s.find(sub); if (p != npos) ...` |
| Заменить подстроку | `s.replace(pos, len, new)` (или комбинация `erase` + `insert`) |
| Изменить регистр | `transform` + `tolower`/`toupper` |
| Проверить символы | `isalpha`, `isdigit` и др. из `<cctype>` |
| Удалить пробелы по краям | `s.erase(0, s.find_first_not_of(" \t"));` и т.п. |
| Разбить строку | написать цикл с `find` и `substr` |
| Склеить список строк | использовать `+=` или `std::ostringstream` |

P. S. В C++ строки — это mutable-контейнеры. Если вы привыкли к неизменяемости Python, помните: здесь вы **можете** менять строку напрямую, и это часто эффективнее.
