# Шпаргалка: Классы в C++

## Что такое класс

**Класс** — это пользовательский тип данных, объединяющий данные (атрибуты) и функции для работы с ними (методы).  
**Объект (экземпляр)** — конкретный экземпляр класса в памяти.

```cpp
#include <string>
using namespace std;

// Класс — чертёж
class Fruit {
    // ...
};

// Объекты — экземпляры класса
Fruit apple;
Fruit banana;
```

**Ключевые термины:**
- **Атрибут (данные)** — переменные внутри класса.
- **Метод (функция-член)** — функция внутри класса.
- **Объект** — экземпляр класса в памяти.

---

## Создание класса

```cpp
class ClassName {
    // тело класса
};
```

**Структура класса**:
1. **Объявление класса** — описывает данные и методы.
2. **Определение методов** — реализация функций.

Имена классов — с **большой буквы** (CamelCase): `MyClass`, `BankAccount`.

**Важно:** В C++ после определения класса обязательно ставится `;`.

---

## Атрибуты и методы

```cpp
class Fruit {
private:
    string name;      // атрибут (данные)
    string color;
    double weight;

public:
    void introduce() {   // метод (функция-член)
        cout << "Я " << name << ", цвет " << color;
    }
};
```

---

## Доступ к членам (`.` и `->`)

```cpp
Fruit apple;               // объект на стеке
apple.introduce();         // доступ через точку

Fruit* ptr = &apple;       // указатель на объект
ptr->introduce();          // доступ через стрелку
```

---

## Модификаторы доступа (Access specifiers)

Определяют, кто может обращаться к членам класса:

| Модификатор | Доступ | 
|-------------|--------|
| **`public`** | Открыто для всех (из любого места) |
| **`protected`** | Только внутри класса и его наследников |
| **`private`** | Только внутри самого класса |

```cpp
class MyClass {
    int defaultVar;        // по умолчанию private!
public:
    int publicVar;         // доступен везде
protected:
    int protectedVar;      // доступен в классе и наследниках
private:
    int privateVar;        // доступен только в классе
};
```

⚠️ В C++ по умолчанию все члены класса — **`private`**.

## Конструкторы и деструктор

### Конструктор (`constructor`)

Вызывается автоматически при создании объекта. Задаёт начальные значения.

```cpp
class Fruit {
private:
    string name;
    double weight;

public:
    // Конструктор с параметрами
    Fruit(string n, double w) {
        name = n;
        weight = w;
    }
    
    // Конструктор по умолчанию
    Fruit() {
        name = "Неизвестный";
        weight = 0;
    }
};

Fruit apple("Яблоко", 150);  // вызов конструктора с параметрами
Fruit empty;                 // вызов конструктора по умолчанию
```

### Деструктор (`destructor`)

Вызывается при уничтожении объекта. Освобождает ресурсы.

```cpp
class Fruit {
public:
    ~Fruit() {
        cout << "Фрукт уничтожен" << endl;
    }
};
```

## `this` указатель

Указывает на текущий объект. Используется внутри методов.

```cpp
class Fruit {
public:
    void set_name(string name) {
        this->name = name;  // this->name — атрибут объекта
    }
};
```

---

## `const`-методы

Методы, которые **не изменяют** объект. Помечаются `const` после параметров.

```cpp
class Fruit {
public:
    string get_name() const {  // не меняет объект
        return name;
    }
};
```

---

## Статические члены (`static`)

Принадлежат **классу**, а не объекту. Существуют в единственном экземпляре.

```cpp
class Fruit {
public:
    static int count;  // объявление статического атрибута
    
    Fruit() {
        count++;       // увеличиваем счётчик при создании
    }
};

int Fruit::count = 0;  // ОБЯЗАТЕЛЬНОЕ определение вне класса
```

## Наследование (`inheritance`)

Класс может наследовать атрибуты и методы от другого класса.

```cpp
// Базовый класс (родитель)
class Animal {
public:
    void eat() {
        cout << "Ем" << endl;
    }
};

// Производный класс (наследник)
class Cat : public Animal {  // public-наследование
public:
    void meow() {
        cout << "Мяу!" << endl;
    }
};

Cat cat;
cat.eat();   // унаследовано от Animal
cat.meow();  // своё
```

**Типы наследования:**
- `public` — public остаётся public
- `protected` — public и protected становятся protected
- `private` — всё становится private

## Полиморфизм и виртуальные функции

**Полиморфизм** — возможность вызывать методы производного класса через указатель на базовый.

### Условия полиморфизма:
1. В базовом классе метод объявлен как `virtual`
2. Производный класс переопределяет (`override`) этот метод
3. Вызов происходит через указатель/ссылку на базовый класс

```cpp
class Shape {
public:
    virtual double area() {   // виртуальная функция
        return 0;
    }
    virtual ~Shape() {}       // виртуальный деструктор!
};

class Circle : public Shape {
private:
    double radius;
public:
    Circle(double r) : radius(r) {}
    
    double area() override {  // переопределение
        return 3.14159 * radius * radius;
    }
};

class Square : public Shape {
private:
    double side;
public:
    Square(double s) : side(s) {}
    
    double area() override {
        return side * side;
    }
};

// Полиморфное использование
Shape* shapes[] = {new Circle(5), new Square(4)};
for (Shape* s : shapes) {
    cout << s->area() << endl;  // вызывается правильный метод!
}
```

### Чисто виртуальные функции (абстрактный класс)

```cpp
class Shape {
public:
    virtual double area() = 0;  // чисто виртуальная — нет реализации
    virtual ~Shape() {}
};
// Shape нельзя создать — это абстрактный класс
// Circle и Square ОБЯЗАНЫ реализовать area()
```

⚠️ **Всегда** делайте деструктор базового класса виртуальным!

## Перегрузка операторов

Позволяет использовать стандартные операторы (`+`, `-`, `==` и др.) с пользовательскими типами.

```cpp
class Vector2D {
private:
    double x, y;
public:
    Vector2D(double x, double y) : x(x), y(y) {}
    
    // Перегрузка оператора +
    Vector2D operator+(const Vector2D& other) const {
        return Vector2D(x + other.x, y + other.y);
    }
    
    // Перегрузка оператора ==
    bool operator==(const Vector2D& other) const {
        return x == other.x && y == other.y;
    }
    
    // Перегрузка оператора вывода
    friend ostream& operator<<(ostream& os, const Vector2D& v) {
        os << "(" << v.x << ", " << v.y << ")";
        return os;
    }
};

Vector2D a(1, 2), b(3, 4);
Vector2D c = a + b;        // работает!
cout << c << endl;         // (4, 6)
```

## Важные отличия от Python

| Особенность | C++ | Python |
|-------------|-----|--------|
| Управление памятью | Ручное (new/delete) или автоматическое (стек) | Автоматическое (GC) |
| Приватность | Реальная (`private` — недоступен снаружи) | По соглашению (`_`) |
| Наследование | Явное (указывается тип) | Автоматическое |
| Полиморфизм | Только через `virtual` | По умолчанию (утиная типизация) |
| Перегрузка операторов | Да, для любых операторов | Ограниченная (магические методы) |
| Объявление vs Определение | Разделяются (.h и .cpp) | Всё в одном файле |
| Деструктор | Есть (`~ClassName()`) | Нет (есть `__del__`) |

## Главное запомнить

| Что нужно | Как сделать в C++ |
|-----------|-------------------|
| Создать класс | `class MyClass { ... };` |
| Создать объект | `MyClass obj;` |
| Создать объект в куче | `MyClass* obj = new MyClass();` |
| Конструктор | `MyClass(parameters) { ... }` |
| Деструктор | `~MyClass() { ... }` |
| Сделать метод виртуальным | `virtual void method();` |
| Сделать метод чисто виртуальным | `virtual void method() = 0;` |
| Переопределить метод | `void method() override;` |
| Защитить данные | Использовать `private` |
| Разрешить доступ наследникам | Использовать `protected` |
| Сделать член общедоступным | Использовать `public` |
| Перегрузить оператор | `ReturnType operator+(const Class& other);` |

P. S. В C++ вы сами управляете памятью и чётко разделяете интерфейс и реализацию. Это даёт больше контроля, но требует больше ответственности.
