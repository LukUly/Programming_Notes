# 📘 Функции в C++

---

## 1. Что такое функция?

**Функция** – именованный блок кода, который можно вызвать многократно.

### Синтаксис:
```cpp
тип_возврата имя_функции(параметры) {
    // тело
    return значение; // если тип не void
}
```

**Пример:**
```cpp
int sum(int a, int b) {
    return a + b;
}
```

**Функция без возврата (`void`):**
```cpp
void printMessage() {
    cout << "Hello!";
}
```

**Прототип (объявление) – пишут перед main:**
```cpp
int sum(int a, int b);   // без тела
```

---

## 2. Сигнатура функции

**Сигнатура** = имя функции + список типов параметров (и их порядок).

Примеры сигнатур:
- `int foo(int, double)` 
- `void bar(char)`

**Важно:** возвращаемый тип в сигнатуру **НЕ входит**! Поэтому нельзя перегрузить функции, отличающиеся только возвращаемым типом.

---

## 3. Перегрузка функций (Overloading)

**Перегрузка** – несколько функций с одним именем, но разными параметрами (тип, количество, порядок).

**Условия:** сигнатуры должны различаться.

```cpp
int max(int a, int b) {
    return (a > b) ? a : b;
}

double max(double a, double b) {
    return (a > b) ? a : b;
}

int max(int a, int b, int c) { // три параметра
    return max(max(a,b), c);
}
```

**Вызов:** компилятор выбирает нужную по аргументам.

## 4. Передача параметров

### 4.1 По значению (копия)
```cpp
void square(int x) {  // x – копия
    x = x * x;        // меняется только копия
}
int a = 5;
square(a);            // a останется 5
```

### 4.2 По ссылке (lvalue‑ссылка)
Параметр становится псевдонимом оригинальной переменной.

```cpp
void squareRef(int& x) {  // ссылка
    x = x * x;            // меняет оригинал
}
int a = 5;
squareRef(a);             // a станет 25
```

**Константная ссылка** – для чтения без копирования:
```cpp
void print(const string& s) { // не копирует, не изменяет
    cout << s;
}
```

### 4.3 По указателю
Передаём адрес переменной. Внутри работаем через разыменование.

```cpp
void squarePtr(int* p) {
    *p = (*p) * (*p);
}
int a = 5;
squarePtr(&a);   // a станет 25
```

### Сравнение:

| Способ | Изменяет оригинал? | Копирование | Обязательная проверка |
|--------|-------------------|-------------|------------------------|
| Значение | ❌ | Да | Нет |
| Ссылка | ✅ | Нет | Нет (всегда ссылается на существующий объект) |
| Указатель | ✅ | Нет (копируется адрес) | Может быть `nullptr` – проверять! |

## 5. Параметры по умолчанию

Можно задать значения по умолчанию (справа налево).

```cpp
void greet(string name = "Гость") {
    cout << "Привет, " << name << "!";
}
greet();          // "Привет, Гость!"
greet("Анна");    // "Привет, Анна!"
```

## 6. Передача переменного числа аргументов

### 6.1 Старый способ (C-style) – `va_list` (не рекомендуется)
```cpp
#include <cstdarg>
int sum(int count, ...) {
    va_list args;
    va_start(args, count);
    int total = 0;
    for (int i = 0; i < count; ++i) {
        total += va_arg(args, int);
    }
    va_end(args);
    return total;
}
// Вызов: sum(3, 10, 20, 30);
```
⚠️ **Опасность:** нет проверки типов.

---

### 6.2 `std::initializer_list` (для однотипных аргументов)
```cpp
#include <initializer_list>
int sum(initializer_list<int> nums) {
    int total = 0;
    for (int n : nums) total += n;
    return total;
}
// Вызов: sum({10, 20, 30});   // фигурные скобки
```

---

### 6.3 Вариативные шаблоны (C++11) – для разных типов

**Рекурсивный подход:**
```cpp
// Базовый случай: один параметр
template<typename T>
void print(T value) {
    cout << value << " ";
}

// Общий случай: голова + хвост
template<typename T, typename... Args>
void print(T first, Args... rest) {
    cout << first << " ";
    print(rest...);   // рекурсивно выводим остальные
}
```

**Использование:**
```cpp
print(10, 3.14, "hello", 'A'); // выведет: 10 3.14 hello A
```

**Сворачивающие выражения (fold expressions) в C++17 – компактнее:**
```cpp
template<typename... Args>
void printAll(Args... args) {
    (cout << ... << args) << '\n';  // левоассоциативная свёртка
}
// Выведет все подряд без пробелов: 103.14helloA
```

Чтобы добавить разделители:
```cpp
template<typename... Args>
void printWithSpace(Args... args) {
    ((cout << args << ' '), ...);   // запятая как разделитель
    cout << '\n';
}
```

## 7. Примеры полных программ

### Пример 1: Перегрузка и ссылки
```cpp
#include <iostream>
using namespace std;

void swap(int& a, int& b) {   // обмен по ссылкам
    int temp = a;
    a = b;
    b = temp;
}

double average(int a, int b) { return (a+b)/2.0; }
double average(double a, double b) { return (a+b)/2.0; }

int main() {
    int x=5, y=10;
    swap(x, y);
    cout << x << " " << y; // 10 5

    cout << average(4, 6) << endl;       // 5
    cout << average(4.5, 6.5) << endl;   // 5.5
    return 0;
}
```

### Пример 2: Передача указателя (с проверкой)
```cpp
void safeSquare(int* p) {
    if (p != nullptr) {
        *p = (*p) * (*p);
    }
}
```

### Пример 3: Вариативный шаблон (сумма произвольных чисел)
```cpp
template<typename... Args>
auto sum(Args... args) {
    return (args + ...);   // fold expression (C++17) – складывает все
}

int main() {
    cout << sum(1, 2, 3, 4.5); // 10.5 (тип выводится как double)
}
```

## 8. Полезные советы

- **Когда использовать ссылки?** Для изменения аргументов или для избегания копирования больших объектов (тогда `const T&`).
- **Когда указатели?** Когда параметр может быть `nullptr` или нужно передать массив/динамическую память.
- **Перегрузка** – удобна для однотипных операций с разными типами.
- **Вариативные шаблоны** – мощный инструмент, но для простых случаев используйте `initializer_list`.
- **Параметры по умолчанию** ставьте в конце списка параметров.
