# Шпаргалка: Строки в Python

## Что такое строка
Строка (`str`) — **неизменяемая** упорядоченная коллекция символов.  
Любая операция, которая «меняет» строку, на самом деле создаёт новую строку.

```python
s = "Привет"
s[0] = 'П'  # Ошибка! Строки нельзя изменять
```

## Индексация и срезы

### Индексы
- Нумерация с **0** (первый символ).
- Отрицательные индексы — с конца (`-1` — последний).

```python
s = "Python"
print(s[0])    # 'P'
print(s[-1])   # 'n'
print(s[5])    # 'n'
print(s[-6])   # 'P'
```

### Срезы (slice)
Синтаксис: `s[start:stop:step]`  
- `start` — включая, `stop` — не включая.
- Если пропустить — начало/конец строки.
- Отрицательный `step` — разворот.

```python
s = "Программирование"
print(s[0:5])       # "Прогр"
print(s[:5])        # "Прогр"
print(s[5:])        # "аммирование"
print(s[::2])       # "Пораиоае" (каждый второй)
print(s[::-1])      # "еинавориммаргоП" (реверс)
```

⚠️ Срезы **никогда** не вызывают ошибку — при выходе за границы просто возвращают пустую строку.

## Основные операции

| Операция | Пример | Результат |
|----------|--------|-----------|
| Длина | `len("abc")` | `3` |
| Конкатенация | `"a" + "b"` | `"ab"` |
| Повторение | `"ha" * 3` | `"hahaha"` |
| Проверка вхождения | `'b' in "abc"` | `True` |
| Сравнение (лексикографически) | `"abc" < "abd"` | `True` |

```python
text = "Hello"
print(len(text))          # 5
print(text + " " + "World")  # "Hello World"
print("lo" in text)       # True
print("He" > "Ha")        # True (т.к. 'e' > 'a')
```

## Методы строк (таблица)

Все методы возвращают новое значение, исходная строка не меняется.

| Категория | Метод | Описание | Пример |
|-----------|-------|----------|--------|
| **Поиск и замена** | `s.find(sub)` | Индекс первого вхождения `sub` или `-1` | `"abc".find("b")` → `1` |
| | `s.rfind(sub)` | Индекс последнего вхождения или `-1` | `"abca".rfind("a")` → `3` |
| | `s.index(sub)` | Как `find`, но вызывает `ValueError` при отсутствии | `"abc".index("b")` → `1` |
| | `s.count(sub)` | Количество непересекающихся вхождений | `"ababa".count("ba")` → `2` |
| | `s.replace(old, new, count)` | Заменяет все (или `count` первых) вхождения `old` на `new` | `"ab".replace("a","x")` → `"xb"` |
| **Регистр** | `s.lower()` | Все буквы строчные | `"Hello".lower()` → `"hello"` |
| | `s.upper()` | Все буквы прописные | `"Hello".upper()` → `"HELLO"` |
| | `s.capitalize()` | Первая буква заглавная, остальные строчные | `"hello world".capitalize()` → `"Hello world"` |
| | `s.title()` | Первая буква каждого слова заглавная | `"hello world".title()` → `"Hello World"` |
| | `s.swapcase()` | Меняет регистр каждой буквы на противоположный | `"HeLLo".swapcase()` → `"hEllO"` |
| **Проверки** | `s.isalnum()` | Состоит только из букв и/или цифр? | `"abc123".isalnum()` → `True` |
| | `s.isalpha()` | Только буквы? | `"abc".isalpha()` → `True` |
| | `s.isdigit()` | Только цифры? | `"123".isdigit()` → `True` |
| | `s.islower()` | Все буквы строчные? (игнорирует не-буквы) | `"abc123".islower()` → `True` |
| | `s.isupper()` | Все буквы прописные? | `"ABC".isupper()` → `True` |
| | `s.isspace()` | Состоит только из пробельных символов (пробелы, табуляции, переносы)? | `" \t\n".isspace()` → `True` |
| **Очистка** | `s.strip()` | Удаляет пробельные символы с начала и конца | `"  hello  ".strip()` → `"hello"` |
| | `s.lstrip()` | Только слева | `"  hello  ".lstrip()` → `"hello  "` |
| | `s.rstrip()` | Только справа | `"  hello  ".rstrip()` → `"  hello"` |
| | (можно передать строку удаляемых символов: `s.strip("!@#")`) | | `"!hello!".strip("!")` → `"hello"` |
| **Начало/конец** | `s.startswith(prefix)` | Начинается с `prefix`? | `"Hello".startswith("He")` → `True` |
| | `s.endswith(suffix)` | Заканчивается на `suffix`? | `"Hello".endswith("lo")` → `True` |
| **Дополнительные** | `s.split(sep)` | Разбивает строку по разделителю, возвращает список | `"a,b,c".split(",")` → `['a','b','c']` |
| | `s.join(iterable)` | Объединяет элементы итерируемого объекта через `s` | `",".join(["a","b"])` → `"a,b"` |

## Обход строки

```python
s = "Python"

# По символам
for ch in s:
    print(ch)

# По индексам
for i in range(len(s)):
    print(i, s[i])

# По индексам и символам (enumerate)
for i, ch in enumerate(s):
    print(f"Индекс {i}: {ch}")
```

## Преобразование в список / кортеж

```python
s = "abc"
print(list(s))   # ['a', 'b', 'c']
print(tuple(s))  # ('a', 'b', 'c')
```

## Полезные функции

| Функция | Описание | Пример |
|---------|----------|--------|
| `ord(ch)` | Код символа (Unicode) | `ord('A')` → `65` |
| `chr(code)` | Символ по коду | `chr(65)` → `'A'` |
| `max(s)` | Максимальный символ (по коду) | `max("abc")` → `'c'` |
| `min(s)` | Минимальный символ | `min("abc")` → `'a'` |
| `sorted(s)` | Возвращает отсортированный список символов | `sorted("cba")` → `['a','b','c']` |

---

## Важные отличия

- **Неизменяемость**: методы всегда возвращают новую строку.
- Сравнение строк — **лексикографическое** (по кодам символов).
- Срезы безопасны — не вызывают `IndexError`.

```python
# Строка не меняется на месте
s = "hello"
s.upper()        # вернёт "HELLO", но s останется "hello"
print(s)         # hello

# Чтобы сохранить результат, нужно присвоить
s = s.upper()    # теперь s = "HELLO"
```

## Главное запомнить

| Что можно? | Как? |
|------------|------|
| Получить символ по индексу | `s[i]` |
| Взять подстроку | `s[start:stop:step]` |
| Найти подстроку | `s.find(sub)` |
| Заменить подстроку | `s.replace(old, new)` |
| Изменить регистр | `s.lower()`, `s.upper()` |
| Проверить содержимое | `s.isdigit()`, `s.isalpha()` и др. |
| Убрать пробелы по краям | `s.strip()` |
| Разбить на слова | `s.split()` |
| Склеить список строк | `','.join(list)` |

P. S. Строка — это неизменяемый поезд. Чтобы изменить состав, нужно построить новый поезд.
