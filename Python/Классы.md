# Шпаргалка: Классы в Python

## Что такое класс

**Класс** — это шаблон (чертёж) для создания объектов.  
**Объект (экземпляр)** — конкретный экземпляр класса, имеющий свои значения атрибутов.

```python
# Класс — рецепт
class Cookie:
    pass

# Экземпляры — печенье по рецепту
c1 = Cookie()
c2 = Cookie()
print(type(c1))  # <class '__main__.Cookie'>
```

**Термины:**
- **Атрибут** — свойство объекта (данные).
- **Метод** — функция внутри класса, работающая с объектом.
- **self** — ссылка на конкретный объект (аналог «я»).

---

## Создание класса

```python
class MyClass:
    """Документация (опционально)"""
    pass  # пустой класс
```

- Имена классов — с **большой буквы** (CamelCase): `MyClass`, `BankAccount`, `Fruit`.
- Для пустого класса обязательно `pass`.

---

## Атрибуты

Можно добавлять атрибуты прямо на лету (но так не рекомендуется):

```python
apple = Fruit()
apple.name = "Яблоко"
apple.color = "красный"
print(apple.name)  # Яблоко
```

⚠️ Если атрибут не существует, обращение вызовет `AttributeError`.

---

## Инициализация (`__init__`)

Специальный метод `__init__` вызывается автоматически при создании объекта.  
Используется для установки начальных атрибутов.

```python
class Fruit:
    def __init__(self, name, color, weight):
        self.name = name
        self.color = color
        self.weight = weight

apple = Fruit("Яблоко", "красный", 150)
print(apple.name)  # Яблоко
```

Можно задавать значения по умолчанию:

```python
class Fruit:
    def __init__(self, name="Неизвестный", color="неизвестный", weight=0):
        self.name = name
        self.color = color
        self.weight = weight
```

## Методы

Метод — это функция внутри класса. Первый параметр **всегда** `self`.

```python
class Fruit:
    def __init__(self, name, color):
        self.name = name
        self.color = color

    def introduce(self):
        print(f"Я {self.name}, мой цвет {self.color}")

apple = Fruit("Яблоко", "красный")
apple.introduce()  # Я Яблоко, мой цвет красный
```

При вызове `apple.introduce()` Python автоматически передаёт `apple` как `self`.

## Инкапсуляция

Скрытие внутреннего состояния и предоставление безопасного интерфейса.

- **Соглашение**: атрибуты, начинающиеся с `_` (одно подчёркивание), считаются «приватными» — не трогать снаружи.
- **Два подчёркивания `__`** (name mangling) — Python переименовывает атрибут, чтобы случайно не перекрыть.

```python
class BankAccount:
    def __init__(self, balance):
        self._balance = balance  # "приватный" по соглашению

    def deposit(self, amount):
        if amount > 0:
            self._balance += amount

    def get_balance(self):
        return self._balance

acc = BankAccount(1000)
acc.deposit(500)
print(acc.get_balance())  # 1500
# print(acc._balance)     # Можно, но невежливо
```

## Магические (dunder) методы

Методы с двойным подчёркиванием в начале и конце. Определяют поведение объектов в разных ситуациях.

| Метод | Назначение | Пример использования |
|-------|------------|----------------------|
| `__init__(self, ...)` | Инициализация | `obj = Class(...)` |
| `__str__(self)` | Красивое строковое представление для пользователей | `print(obj)`, `str(obj)` |
| `__repr__(self)` | Техническое представление для разработчиков | `repr(obj)`, вывод в списках |
| `__len__(self)` | Возвращает длину | `len(obj)` |
| `__add__(self, other)` | Сложение | `obj1 + obj2` |
| `__eq__(self, other)` | Сравнение на равенство | `obj1 == obj2` |
| `__lt__(self, other)` | Меньше (`<`) | сортировка |
| `__call__(self, ...)` | Объект можно вызывать как функцию | `obj()` |
| `__getitem__(self, key)` | Доступ по индексу/ключу | `obj[key]` |
| `__setitem__(self, key, value)` | Присваивание по индексу | `obj[key] = val` |

Пример:

```python
class Circle:
    def __init__(self, radius):
        self.radius = radius

    def __str__(self):
        return f"Круг радиуса {self.radius}"

    def __repr__(self):
        return f"Circle(radius={self.radius})"

    def __add__(self, other):
        return Circle(self.radius + other.radius)

c = Circle(10)
print(c)          # Круг радиуса 10
print(repr(c))    # Circle(radius=10)
c2 = c + Circle(5)  # __add__
print(c2.radius)  # 15
```

## Полиморфизм и утиная типизация

**Полиморфизм** — способность объектов разных классов реагировать на одну и ту же команду по-своему.  
**Утиная типизация** — если объект имеет нужные методы, он подходит, независимо от типа.

```python
class Cat:
    def speak(self):
        return "Мяу!"

class Dog:
    def speak(self):
        return "Гав!"

class Parrot:
    def speak(self):
        return "Помогите!"

def make_sound(animal):
    print(animal.speak())

animals = [Cat(), Dog(), Parrot()]
for a in animals:
    make_sound(a)   # Работает для всех, у всех есть speak()
```

## Полезные функции

| Функция | Описание | Пример |
|---------|----------|--------|
| `type(obj)` | Возвращает класс объекта | `type(10)` → `int` |
| `isinstance(obj, Class)` | Проверяет, является ли объект экземпляром класса или его наследником | `isinstance(apple, Fruit)` → `True` |
| `hasattr(obj, attr)` | Есть ли атрибут? | `hasattr(apple, 'name')` → `True` |
| `getattr(obj, attr, default)` | Получить атрибут или default | `getattr(apple, 'color', 'unknown')` |
| `setattr(obj, attr, val)` | Установить атрибут | `setattr(apple, 'price', 100)` |

---

## Важные отличия от других языков

- Всё является объектом: числа, строки, функции, классы.
- Атрибуты можно добавлять на лету (динамичность).
- Нет строгой приватности — только соглашения.
- Наследование (не рассмотрено в материалах, но присутствует) — один класс может наследовать от другого.

## Главное запомнить

| Что нужно | Как сделать |
|-----------|-------------|
| Создать класс | `class MyClass:` |
| Создать объект | `obj = MyClass()` |
| Инициализировать атрибуты | `def __init__(self, ...): self.attr = ...` |
| Определить метод | `def method(self, ...):` |
| Сделать атрибут «приватным» | по соглашению `_attr` |
| Красивое строковое представление | `def __str__(self):` |
| Техническое представление | `def __repr__(self):` |
| Проверить тип | `isinstance(obj, Class)` |
| Реализовать полиморфизм | создать методы с одинаковыми именами в разных классах |

P. S. Классы — это способ организовать код вокруг данных и действий над ними. Помните: методы делятся, а атрибуты — каждому своё.
