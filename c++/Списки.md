# 📘 Шпаргалка по спискам и словарям в C++

## 1. Списки (последовательные контейнеры)

### 1.1 `std::vector` – динамический массив

**Подключение:** `#include <vector>`

**Характеристики:**
- Хранит элементы в **непрерывной области памяти**
- Поддерживает **быстрый доступ по индексу** – O(1)
- **Вставка/удаление в конце** – O(1)
- **Вставка/удаление в середине** – O(n) – требует сдвига элементов
- Автоматически расширяется при необходимости

**Создание:**
```cpp
#include <vector>
using namespace std;

vector<int> v1;                    // пустой вектор
vector<int> v2(5);                 // 5 элементов, инициализированных 0
vector<int> v3(3, 10);             // {10, 10, 10}
vector<int> v4 = {1, 2, 3, 4, 5};  // список инициализации (C++11)
vector<int> v5(v4);                // копирование
```

**Основные операции:**
```cpp
vector<int> v = {10, 20, 30};

// ----- РАЗМЕР -----
v.size();          // количество элементов (3)
v.empty();         // true если пуст
v.capacity();      // текущая выделенная память

// ----- ДОБАВЛЕНИЕ -----
v.push_back(40);   // добавить в конец → {10, 20, 30, 40}
v.insert(v.begin(), 5);      // вставить в начало → {5, 10, 20, 30, 40}
v.insert(v.begin() + 2, 15); // вставить по индексу 2

// ----- УДАЛЕНИЕ -----
v.pop_back();      // удалить последний элемент
v.erase(v.begin());          // удалить первый элемент
v.erase(v.begin() + 1);      // удалить элемент по индексу 1
v.clear();         // удалить все элементы

// ----- ДОСТУП -----
int first = v.front();   // первый элемент
int last = v.back();     // последний элемент
int val1 = v[0];         // доступ по индексу (без проверки)
int val2 = v.at(2);      // доступ с проверкой границ

// ----- ПЕРЕБОР -----
for (int x : v) {                // range-based for (C++11)
    cout << x << " ";
}

for (size_t i = 0; i < v.size(); ++i) {
    cout << v[i] << " ";
}

for (auto it = v.begin(); it != v.end(); ++it) {
    cout << *it << " ";
}
```

**Временная сложность:**

| Операция | Сложность |
|----------|-----------|
| Доступ по индексу | O(1) |
| Вставка в конец | O(1) |
| Вставка в середину/начало | O(n) |
| Удаление с конца | O(1) |
| Удаление из середины/начала | O(n) |
| Поиск элемента | O(n) |

**Когда использовать:** частый доступ по индексу, операции только в конце

### 1.2 `std::list` – двусвязный список

**Подключение:** `#include <list>`

**Характеристики:**
- Элементы **не хранятся непрерывно** – каждый элемент содержит указатели на соседей
- **Быстрая вставка/удаление в любом месте** – O(1)
- **Нет доступа по индексу** – нужно проходить по списку

**Основные операции:**
```cpp
#include <list>
using namespace std;

list<int> lst = {1, 2, 3};

// ----- ДОБАВЛЕНИЕ -----
lst.push_back(4);        // в конец → {1, 2, 3, 4}
lst.push_front(0);       // в начало → {0, 1, 2, 3, 4}
auto it = lst.begin();
advance(it, 2);          // переместить итератор на позицию 2
lst.insert(it, 99);      // вставить перед it

// ----- УДАЛЕНИЕ -----
lst.pop_back();          // удалить последний
lst.pop_front();         // удалить первый
lst.erase(it);           // удалить элемент по итератору
lst.remove(2);           // удалить все элементы со значением 2
lst.unique();            // удалить дубликаты (список должен быть отсортирован)

// ----- ДОСТУП -----
int first = lst.front(); // первый элемент
int last = lst.back();   // последний элемент
// НЕТ ОПЕРАТОРА [] или at() – только перебор!

// ----- ПЕРЕБОР -----
for (int x : lst) {
    cout << x << " ";
}

for (auto it = lst.begin(); it != lst.end(); ++it) {
    cout << *it << " ";
}

// ----- СПЕЦИФИЧЕСКИЕ ОПЕРАЦИИ -----
lst.sort();              // сортировка списка
lst.reverse();           // развернуть список
lst.merge(lst2);         // слияние двух отсортированных списков
lst.splice(it, lst2);    // перенести элементы из lst2 в lst
```

**Когда использовать:** частые вставки/удаления в середине, не нужен доступ по индексу

### 1.3 `std::deque` – двухсторонняя очередь

**Подключение:** `#include <deque>`

**Характеристики:**
- Быстрая вставка/удаление **и в начале, и в конце** – O(1)
- Поддерживает **доступ по индексу** – O(1)
- Как `vector`, но с эффективным `push_front`/`pop_front`

**Основные операции:**
```cpp
#include <deque>
using namespace std;

deque<int> d = {1, 2, 3};

d.push_back(4);          // в конец
d.push_front(0);         // в начало
d.pop_back();            // удалить с конца
d.pop_front();           // удалить с начала

int val = d[2];          // доступ по индексу
int first = d.front();   // первый
int last = d.back();     // последний

d.insert(d.begin() + 1, 99); // вставка по индексу
d.erase(d.begin() + 1);      // удаление по индексу
```

**Когда использовать:** нужны частые операции и в начале, и в конце

### 1.4 `std::array` – статический массив (C++11)

**Подключение:** `#include <array>`

**Характеристики:**
- **Фиксированный размер** – известен на этапе компиляции
- **Нет динамического выделения памяти** – очень быстрый
- Поддерживает доступ по индексу – O(1)

```cpp
#include <array>
using namespace std;

array<int, 5> arr = {1, 2, 3, 4, 5};  // размер обязателен
arr[2] = 10;             // изменение по индексу
int val = arr.at(3);     // доступ с проверкой
int first = arr.front(); // первый элемент
int last = arr.back();   // последний элемент
arr.fill(0);             // заполнить все элементы нулями

for (int x : arr) {      // перебор
    cout << x << " ";
}
```

**Когда использовать:** размер известен заранее и не меняется

## 2. Словари (ассоциативные контейнеры)

### 2.1 `std::map` – упорядоченный словарь

**Подключение:** `#include <map>`

**Характеристики:**
- Хранит **пары (ключ → значение)**
- Ключи **уникальные** и **автоматически сортируются** (по умолчанию по возрастанию)
- Реализован на **красно-чёрном дереве**
- Все операции – O(log n)

**Создание и основные операции:**
```cpp
#include <map>
#include <string>
using namespace std;

map<string, int> ages;                    // пустой словарь

// ----- ДОБАВЛЕНИЕ -----
ages["Alice"] = 25;                       // через оператор []
ages.insert({"Bob", 30});                 // через insert (C++11)
ages.insert(pair<string, int>("Charlie", 35));
ages.emplace("David", 40);               // C++11 – эффективнее

// ----- ДОСТУП -----
int age1 = ages["Alice"];                // если ключа нет – создаст со значением 0!
int age2 = ages.at("Bob");               // at() – проверит существование
// at() выбросит исключение, если ключа нет

// ----- ПРОВЕРКА СУЩЕСТВОВАНИЯ -----
if (ages.find("Alice") != ages.end()) {  // find() возвращает итератор
    cout << "Alice найдена!";
}

if (ages.count("Bob") > 0) {             // count() – количество вхождений (0 или 1)
    cout << "Bob есть!";
}

// ----- УДАЛЕНИЕ -----
ages.erase("Alice");                     // удалить по ключу
ages.erase(ages.begin());                // удалить первый элемент

// ----- ПЕРЕБОР -----
for (const auto& pair : ages) {          // range-based for
    cout << pair.first << ": " << pair.second << endl;
}

for (auto it = ages.begin(); it != ages.end(); ++it) {
    cout << it->first << ": " << it->second << endl;
}

// ----- РАЗМЕР -----
ages.size();          // количество пар
ages.empty();         // true если пуст
ages.clear();         // удалить всё
```

**Особенности:**
- Элементы всегда **отсортированы по ключу**
- `operator[]` **создаёт** элемент, если его нет – будьте осторожны!
- Используйте `at()` или `find()` для безопасного доступа

**Временная сложность:**

| Операция | Сложность |
|----------|-----------|
| Вставка | O(log n) |
| Доступ по ключу | O(log n) |
| Удаление по ключу | O(log n) |
| Поиск | O(log n) |

**Когда использовать:** нужен **отсортированный** словарь, важен порядок ключей

---

### 2.2 `std::unordered_map` – неупорядоченный словарь (хеш-таблица)

**Подключение:** `#include <unordered_map>`

**Характеристики:**
- Хранит **пары (ключ → значение)**
- **Нет порядка** – элементы не сортируются
- Реализован на **хеш-таблице**
- **Очень быстрый** – все операции в среднем O(1)

```cpp
#include <unordered_map>
#include <string>
using namespace std;

unordered_map<string, int> scores;        // пустой словарь

// ----- ДОБАВЛЕНИЕ (как в map) -----
scores["Alice"] = 95;
scores.insert({"Bob", 87});
scores.emplace("Charlie", 92);

// ----- ДОСТУП (как в map) -----
int score1 = scores["Alice"];             // создаст, если нет
int score2 = scores.at("Bob");            // безопасный доступ

// ----- ПРОВЕРКА СУЩЕСТВОВАНИЯ (как в map) -----
if (scores.find("Alice") != scores.end()) {
    cout << "Alice найдена!";
}

// ----- УДАЛЕНИЕ (как в map) -----
scores.erase("Alice");

// ----- ПЕРЕБОР (как в map, но порядок НЕ ГАРАНТИРУЕТСЯ) -----
for (const auto& pair : scores) {
    cout << pair.first << ": " << pair.second << endl;
}

// ----- РАЗМЕР -----
scores.size();
scores.empty();
scores.clear();
```

**Сравнение `map` и `unordered_map`:**

| Характеристика | `map` | `unordered_map` |
|----------------|-------|-----------------|
| Упорядоченность | ✅ по ключу | ❌ нет порядка |
| Скорость | O(log n) | O(1) в среднем |
| Реализация | Красно-чёрное дерево | Хеш-таблица |
| Когда использовать | Нужен порядок ключей | Нужна максимальная скорость |

---

### 2.3 `std::multimap` – словарь с дублирующимися ключами

**Подключение:** `#include <map>`

**Отличие от `map`:** позволяет **хранить несколько значений с одинаковым ключом**

```cpp
#include <map>
using namespace std;

multimap<string, int> mm;
mm.insert({"Alice", 25});
mm.insert({"Alice", 30});   // можно! два значения с ключом "Alice"
mm.insert({"Bob", 20});

// ----- ПОИСК ВСЕХ ЗНАЧЕНИЙ ПО КЛЮЧУ -----
auto range = mm.equal_range("Alice");
for (auto it = range.first; it != range.second; ++it) {
    cout << it->second << " ";   // выведет 25 30
}

// ----- ИЛИ -----
auto it = mm.find("Alice");
while (it != mm.end() && it->first == "Alice") {
    cout << it->second << " ";
    ++it;
}
```

## 3. Сравнение контейнеров

### Списки:

| Контейнер | Доступ по индексу | Вставка в начало | Вставка в конец | Вставка в середину | Память |
|-----------|-------------------|------------------|-----------------|-------------------|--------|
| `vector` | O(1) ✅ | O(n) | O(1) ✅ | O(n) | непрерывная |
| `list` | ❌ | O(1) ✅ | O(1) ✅ | O(1) ✅ | не непрерывная |
| `deque` | O(1) ✅ | O(1) ✅ | O(1) ✅ | O(n) |分段ная |

### Словари:

| Контейнер | Упорядочен | Скорость | Дубликаты ключей |
|-----------|------------|----------|------------------|
| `map` | ✅ по ключу | O(log n) | ❌ |
| `unordered_map` | ❌ | O(1) | ❌ |
| `multimap` | ✅ по ключу | O(log n) | ✅ |

## 4. Примеры полных программ

### Пример 1: Работа с vector – статистика чисел
```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    vector<int> numbers = {5, 2, 8, 1, 9, 3};

    // Добавление
    numbers.push_back(7);
    numbers.insert(numbers.begin() + 2, 4);

    // Сортировка
    sort(numbers.begin(), numbers.end());

    // Вывод
    cout << "Отсортированные числа: ";
    for (int x : numbers) {
        cout << x << " ";
    }
    // Вывод: 1 2 3 4 5 7 8 9

    // Удаление дубликатов
    numbers.erase(unique(numbers.begin(), numbers.end()), numbers.end());

    return 0;
}
```

### Пример 2: Телефонная книга (map)
```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    map<string, string> phoneBook;

    // Добавление контактов
    phoneBook["Alice"] = "+7-999-123-45-67";
    phoneBook["Bob"] = "+7-999-234-56-78";
    phoneBook["Charlie"] = "+7-999-345-67-89";

    // Поиск
    string name;
    cout << "Введите имя: ";
    cin >> name;

    auto it = phoneBook.find(name);
    if (it != phoneBook.end()) {
        cout << "Телефон: " << it->second << endl;
    } else {
        cout << "Контакт не найден!" << endl;
    }

    // Вывод всех контактов (отсортированы по имени!)
    cout << "\nВсе контакты:" << endl;
    for (const auto& entry : phoneBook) {
        cout << entry.first << ": " << entry.second << endl;
    }

    return 0;
}
```

### Пример 3: Подсчёт слов (unordered_map)
```cpp
#include <iostream>
#include <unordered_map>
#include <string>
#include <sstream>
using namespace std;

int main() {
    string text = "apple banana apple cherry banana apple";
    unordered_map<string, int> wordCount;

    stringstream ss(text);
    string word;
    while (ss >> word) {
        wordCount[word]++;   // увеличиваем счётчик
    }

    // Вывод статистики
    for (const auto& pair : wordCount) {
        cout << pair.first << ": " << pair.second << endl;
    }
    // Пример вывода (порядок может быть любым):
    // cherry: 1
    // apple: 3
    // banana: 2

    return 0;
}
```

### Пример 4: Студенты и оценки (multimap)
```cpp
#include <iostream>
#include <map>
#include <string>
using namespace std;

int main() {
    multimap<string, int> grades;

    grades.insert({"Alice", 85});
    grades.insert({"Alice", 92});
    grades.insert({"Bob", 78});
    grades.insert({"Alice", 90});

    // Все оценки Alice
    cout << "Оценки Alice: ";
    auto range = grades.equal_range("Alice");
    for (auto it = range.first; it != range.second; ++it) {
        cout << it->second << " ";
    }
    cout << endl;  // 85 92 90

    return 0;
}
```

## 5. Полезные советы

- **По умолчанию используйте `vector`** – это самый универсальный контейнер
- Для частых вставок в середину – `list`
- Для частых вставок в начало и конец – `deque`
- Если размер известен заранее – `array`
- Для словарей: **нужен порядок** → `map`, **нужна скорость** → `unordered_map`
- `operator[]` в map/unordered_map **создаёт** элемент – используйте `at()` или `find()` для безопасного доступа
- Все контейнеры поддерживают range-based for (`for (auto x : container)`)
- Для вывода контейнера в шпаргалке: используйте перебор
