# Шпаргалка: Кортежи в Python

## Что такое кортеж

**Кортеж** (`tuple`) — **неизменяемая** упорядоченная коллекция, которая может содержать элементы любых типов.  
В отличие от списков, кортеж нельзя изменить после создания (нельзя добавлять, удалять или менять элементы).

```python
# Кортеж из трёх элементов
t = (42, "Python", True)

# Кортеж без скобок (запятая обязательна)
t2 = 1, 2, 3

# Пустой кортеж
empty = ()

# Кортеж из одного элемента (запятая обязательна!)
single = (18,)
```

---

## Создание кортежа

```python
# Из кода
numbers = (1, 2, 3, 4, 5)

# Из строки (получаем кортеж символов)
chars = tuple('hello')   # ('h', 'e', 'l', 'l', 'o')

# Из списка
items = tuple(['a', 'b', 'c'])   # ('a', 'b', 'c')

# Из range
nums = tuple(range(5))   # (0, 1, 2, 3, 4)

# Без скобок (запятая создаёт кортеж)
coords = 10, 20, 30      # (10, 20, 30)
```

---

## Доступ к элементам

```python
t = ('ёж', 'кит', 'слон', 'питон')

print(t[0])    # ёж (первый)
print(t[-1])   # питон (последний)

# Срезы
print(t[1:3])   # ('кит', 'слон')
print(t[::-1])  # ('питон', 'слон', 'кит', 'ёж') (разворот)
```

⚠️ При попытке изменить элемент — ошибка `TypeError`:

```python
t[0] = 'медведь'  # TypeError: 'tuple' object does not support item assignment
```

## Основные операции

| Операция | Пример | Результат |
|----------|--------|-----------|
| Длина | `len(t)` | количество элементов |
| Проверка вхождения | `'кит' in t` | `True` |
| Конкатенация | `(1,2) + (3,4)` | `(1,2,3,4)` |
| Повторение | `(1,2) * 3` | `(1,2,1,2,1,2)` |
| Сравнение (лексикографическое) | `(1,2) < (1,3)` | `True` |

```python
a = (10, 20)
b = (30, 40)
c = a + b        # (10, 20, 30, 40)
d = a * 3        # (10, 20, 10, 20, 10, 20)
print(len(c))    # 4
print(20 in a)   # True
```

## Методы кортежей

Методов всего два (поскольку кортеж неизменяем):

| Метод | Описание | Пример |
|-------|----------|--------|
| `t.count(el)` | Количество вхождений элемента `el` | `(1,2,2,3).count(2)` → `2` |
| `t.index(el, start, end)` | Индекс первого вхождения `el` (можно указать диапазон) | `(1,2,3).index(2)` → `1` |

```python
t = ('пепперони', 'пепперони', 'барбекю', '4 сыра')
print(t.count('пепперони'))  # 2
print(t.index('барбекю'))    # 2
```

⚠️ Если элемент не найден, `index()` выбрасывает `ValueError`.

## Обход кортежа

```python
t = ('a', 'b', 'c')

# По элементам
for item in t:
    print(item)

# По индексам
for i in range(len(t)):
    print(i, t[i])

# По индексам и элементам
for i, val in enumerate(t):
    print(i, val)
```

## Сравнение кортежей

Кортежи сравниваются **поэлементно** (лексикографически): сначала первые элементы, затем вторые и т.д.  
Важно, чтобы элементы на одинаковых позициях были сравнимы между собой.

```python
print((1, 2, 3) == (1, 2, 3))  # True
print((1, 2, 3) < (1, 2, 4))   # True (3 < 4)
print((1, 2) < (1, 2, 0))      # True (первый короче)
print((1, 2, 'a') < (1, 2, 'b'))  # True (лексикографически)
# print((1, 2, 'a') < (1, 2, 3))   # TypeError: сравнивать int и str нельзя
```

### Пример приоритетного сравнения

```python
# Кортежи позволяют сортировать по нескольким критериям
student1 = (4.9, 4.8, 5.0, -ord('Х'), 'Хайруллин')
student2 = (4.9, 4.7, 5.0, -ord('Ц'), 'Цицюра')
best = max(student1, student2)
print(best[-1])  # лучшая фамилия по критериям
```

## Распаковка кортежей

```python
t = (1, 2, 3)
a, b, c = t        # a=1, b=2, c=3

# Со звёздочкой (собирает остаток)
first, *middle, last = (1, 2, 3, 4, 5)
print(first)   # 1
print(middle)  # [2, 3, 4]
print(last)    # 5

# Распаковка в цикле
pairs = [(1, 'a'), (2, 'b')]
for num, letter in pairs:
    print(num, letter)
```

## Преобразование

```python
# Кортеж → список
t = (1, 2, 3)
lst = list(t)        # [1, 2, 3]

# Кортеж → строка
t = ('a', 'b', 'c')
s = ''.join(t)       # "abc" (только для строковых элементов)

# Строка → кортеж
t = tuple('abc')     # ('a', 'b', 'c')

# Список → кортеж
t = tuple([1, 2, 3]) # (1, 2, 3)
```

---

## Полезные функции

| Функция | Описание | Пример |
|---------|----------|--------|
| `max(t)` | Максимальный элемент (если все сравнимы) | `max((1,5,3))` → `5` |
| `min(t)` | Минимальный элемент | `min((1,5,3))` → `1` |
| `sum(t)` | Сумма элементов (только числа) | `sum((1,2,3))` → `6` |
| `sorted(t)` | Возвращает отсортированный список | `sorted((3,1,2))` → `[1,2,3]` |

---

## Важные отличия от списков

| Свойство | Кортеж | Список |
|----------|--------|--------|
| Изменяемость | ❌ Неизменяемый | ✅ Изменяемый |
| Синтаксис | `()` или запятая | `[]` |
| Методы | только `.count()` и `.index()` | множество (`.append()`, `.pop()` и др.) |
| Скорость | чуть быстрее | чуть медленнее |
| Использование как ключ словаря | ✅ Можно | ❌ Нельзя (нехешируемый) |
| Занимаемая память | меньше | больше |

---

## Главное запомнить

| Что нужно | Как сделать |
|-----------|-------------|
| Создать кортеж | `t = (1, 2, 3)` или `t = 1, 2, 3` |
| Создать кортеж из одного элемента | `t = (42,)` (запятая обязательна!) |
| Получить элемент по индексу | `t[i]` |
| Взять срез | `t[start:stop:step]` |
| Проверить вхождение | `el in t` |
| Найти индекс элемента | `t.index(el)` |
| Подсчитать количество вхождений | `t.count(el)` |
| Распаковать в переменные | `a, b = t` |
| Преобразовать в список | `list(t)` |
| Использовать как ключ словаря | `d = {t: "value"}` |

P. S. Кортеж — это «замороженный» список. Используйте его, когда данные не должны меняться, или когда нужен ключ для словаря.
